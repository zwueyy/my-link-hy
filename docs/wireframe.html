영역별 구조 명세 (Component Breakdown)

① 상단 헤더 & 프로필 영역

• TopBar: 로고, + 링크 추가 액션, ⚙️ 설정 모달 진입점
• Avatar & Badge: 80px 프로필 사진 + 온라인 활성 뱃지
• 소셜 아이콘 바: 인스타그램, 유튜브, 깃허브 등 원클릭 이동
• 문의하기 CTA: 핵심 전환(Conversion) 액션 버튼

② 요약 통계 타일 (Stats Tile)

• 등록 링크 수, 누적 클릭 수, 금일 방문자 수, 수신된 문의 수를 고정폭 숫자(tabular-nums)로 직관적 표시

③ 링크 카드 스트림 (ListRow)

• 검색 및 카테고리 필터링 칩 제공
• 44px 카테고리별 소프트 컬러 아이콘 컨테이너
• 볼드 타이틀 + 서브 설명 + 실시간 클릭 수 카운터
• 클릭 시 새 창 열림 및 Zustand incrementClicks 호출

⚙️ 설정(Settings) 모달 스펙

숨김 레이어

메인 화면의 미니멀리즘을 유지하기 위해 테마 선택기와 프로필 설정은 모달 내부에 배치됩니다:

  • 8종 테마 프리셋 선택 및 즉시 적용
  • 프로필 이미지 URL, 이름, 바이오 수정
  • 소셜 미디어 링크 URL 관리
  • 수신된 문의함 (메시지 읽음/삭제/답장)
  • LocalStorage 자동 동기화
